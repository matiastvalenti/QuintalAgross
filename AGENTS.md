# Reglas para el agente

Trabajá con cambios mínimos y puntuales.

Antes de editar:

- Leé solo los archivos necesarios.
- No recorras todo el proyecto si no hace falta.
- No hagas refactors grandes sin permiso.
- No reescribas archivos completos.
- No cambies nombres de variables, rutas o modelos si no es necesario.

Al responder:

- Explicá brevemente qué vas a tocar.
- Mostrá qué archivos modificaste.
- Si hay duda, preguntá antes.

Para backend:

- Mantener la estructura actual del proyecto.
- No inventar campos nuevos si ya existen.
- Revisar primero modelos, schemas, services y routes relacionados.

Para frontend:

- Cambiar solo el componente necesario.
- No modificar estilos globales salvo que se pida.
- No rehacer pantallas completas.

Objetivo principal:
Consumir poco contexto y resolver la tarea con la menor cantidad de cambios posible.
